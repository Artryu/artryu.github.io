🎮 Steam and Game Pass Save Locations

The same game can store its save files in different places depending on how you installed it. A Steam copy keeps its data inside your Steam user folder, while a Game Pass copy keeps its data in the Windows gaming storage area. The two setups do not share a folder, which is exactly why manual backups go wrong so often.

This utility includes a save-location workflow for both cases. Choose the launcher you play through and the application narrows the search to the correct family of folders. From there it lists what it found so you can confirm the right save before copying anything.

🗂️ Creating a Restore Point

  1. Open the application and confirm the save file it has detected is the one you play.
  2. Select the create backup option.
  3. Type a short description so you will recognize this moment later.
  4. Confirm, and wait for the confirmation message.
  5. Note the date and time shown in the list — that is your new restore point.

Good moments to create a restore point include finishing a long dungeon run, changing your gear setup dramatically, installing a game update, and before trying anything you are unsure about.

↩️ Restoring an Earlier Save

  1. Close Minecraft Dungeons II completely before you begin.
  2. Open the application and find the restore point you want in the list.
  3. Select it and choose the restore option.
  4. Read the confirmation message and accept it.
  5. Start the game again and check your progress.

The application keeps a copy of the save it replaced, so if you restore the wrong point you can step back to the one you had a moment ago.

🧭 Simple Habits That Protect Your Progress

Backups work best when they are a small routine instead of a rescue mission. Create a restore point at the end of each play session. If you finish a session that felt important, add one with a clear name. Once a month, copy your backup folder onto a USB drive or an external disk so a hardware problem cannot take both the save and the copies with it. Delete old restore points you know you will never need, keeping the list short and easy to read.

❓ Frequently Asked Questions

Do I need to install anything else?

No. The application runs on a Windows PC and handles the backup work itself. Just download it from the link above and start it.

Will this change my game files?

Only when you choose to restore a restore point. Making a backup is a read-only copy and leaves your live save untouched.

Can I keep backups for both Steam and Game Pass?

Yes. Each save location can have its own set of restore points, and the list shows which source each backup came from.

How many backups should I keep?

Most players are comfortable with five to ten recent restore points plus one older copy kept aside for a rainy day. There is no fixed limit built into the tool.

Where do my backups go?

Into a backup folder created by the application on your own drive. The exact path is shown inside the app so you can open it in File Explorer at any time.

🛠️ If Something Looks Wrong

If the application does not find your save, close the game first and try again — an open game can lock the file. If a restore seems to have no effect, confirm you closed the game before restoring and that you picked the restore point with the date you expected. If the window does not open at all, download the file again from the link above, save it to a fresh folder, and start it from there. Most problems come down to a locked save file or a partial download.
